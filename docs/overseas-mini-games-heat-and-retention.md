# 海外小游戏热度与粘性调研

> **面向对象**：海外用户（欧美、东南亚、拉美、中东等）  
> **产品形态**：Web / Instant Games / 社交内嵌小游戏 / 页游聚合平台  
> **当前产品方向**：**多款小游戏各自独立 App** → 详见 [多 App 矩阵策略](./multi-app-portfolio-strategy.md)  
> **更新**：2026-07

---

## 1. 结论摘要（TL;DR）

| 维度 | 关键判断 |
|------|----------|
| **热度** | Instant / 浏览器小游戏市场 2025 年约 **$3.5B–$5.1B**，2033 年前 CAGR **10%–18%**；TikTok Mini Games 子赛道增速更高（~18% CAGR） |
| **流量入口** | **Poki / CrazyGames** 代表 Web 聚合；**Facebook / TikTok / Discord** 代表社交内嵌；**PWA** 作为绕开应用商店 friction 的分发补充 |
| **粘性本质** | 超休闲/Instant 类 **D30 留存 1%–4% 是常态**，商业模式靠 **高量低 CPI + 广告变现**，不是长留存；Hybrid Casual / 社交化可拉高 D7/D30 |
| **核心 KPI** | 留存 **D1/D7/D30** + 粘性 **DAU/MAU** + 会话 **时长/频次**；Web 端额外关注 **首屏加载 <8s**、**零安装转化率** |
| **聚合平台机会** | 策展质量（Curation）+ 跨游戏账号/进度 + 社交排行榜 + 开发者数据面板，是 Poki 等平台拉开差距的关键 |
| **App + IAA 方向** | 每 App 独立变现；收入看 **ARPDAU × 留存**；矩阵看 **Portfolio LTV + Cross-Promo** |

## 2. 赛道定义：海外「小游戏」指什么

在本项目中，「小游戏」主要指以下重叠形态（均 **无需或极低安装成本**）：

| 形态 | 典型平台 | 特点 |
|------|----------|------|
| **Browser Games** | Poki, CrazyGames, Kongregate | HTML5，浏览器即开即玩，SEO + 策展驱动 |
| **Instant Games** | Facebook Gaming, Messenger | 社交图谱、分享裂变、Audience Network 广告 |
| **Platform Mini Games** | TikTok Mini Program, Telegram Mini App | 短视频/IM 流量内嵌，发现路径短 |
| **Social Activities** | Discord Activities | 语音频道内多人同玩，强社交绑定 |
| **PWA / Web App** | 独立落地页 + Add to Home Screen | 绕开商店、Push 再触达，适合买量团队 |

与 **Native App Store 超休闲** 的区别：Web/Instant 侧 **获客 friction 更低**，但 **推送与系统级留存工具更弱**，更依赖 **平台内发现、SEO、社交分享、再营销**。

## 3. 市场热度

### 3.1 整体规模与增速

| 来源 | 2025 估值 | 远期预测 | CAGR |
|------|-----------|----------|------|
| Verified Market Research（Instant Games） | ~$5.10B | $11.58B（2033） | 10.8% |
| Coherent Market Insights | $3.53B（2026 基准） | $8.72B（2033） | 13.8% |
| WiseGuy（TikTok Mini Program Games） | $2.75B | $15B（2035） | 18.4% |
| DataIntelo（Browser Game 广义） | $11.8B（2026） | $16.3B（2034） | 3.5% |

**解读**：

- **Instant / 平台内小游戏** 增速高于传统 Browser Game 大盘（后者基数大、增速缓）。
- **移动端占 Instant Games ~72%**（Coherent），海外聚合平台必须 **Mobile Web 优先**。
- **82% 的 30 岁以下玩家** 通过社交媒体接触 Instant Games（Market Growth Reports），社交渠道是热度放大器。

### 3.2 头部平台流量（公开披露）

| 平台 | 规模指标 | 备注 |
|------|----------|------|
| **Poki** | **1 亿 MAU**；2025 年 625M 独立玩家访问；月 **110 亿次** gameplay | 全球最大 Web 游戏平台之一；1500+ 游戏 |
| **CrazyGames** | 约 **3000 万+** 月访客（第三方估算）；与 Poki 合计约 **9500 万** 月玩家量级 | 与 Poki 直接竞品 |
| **Facebook Instant Games** | 历史披露 **3.5 亿+** MAU 量级（社交 Instant 赛道龙头） | Meta 2023 起开放更早阶段分发 |
| **TikTok Mini Games** | 已覆盖美、印尼、泰、菲、越、马、巴西、沙特、土耳其等 | 2025 生态仍处 **流量红利窗口** |
| **Discord** | 2025.12：有好友在 Discord 时 PC 玩家游玩时长 **中位数 ×6**（3 位好友 ×8） | Activities 面向 **社交同玩**，非纯单机超休闲 |

### 3.3 热度驱动因素

1. **零摩擦**：无下载、无注册（或延迟注册）→ 降低首次体验成本  
2. **策展（Curation）**：Poki 强调「质量筛选」而非纯数量，227 款新作中 Top 游戏靠策展出圈  
3. **社交裂变**：分享成绩、邀请好友、Discord Referral Link  
4. **买量成本**：TikTok Mini Games 早期案例 CPA 可至 **$0.20**，D1 ROAS >120%（Mobvista 案例，需独立验证）  
5. **Hybrid 化**：超休闲叠加 Meta 层（收集、Battle Pass、LiveOps）→ 2023 年 Hyper-casual D30 从 1.8% 升至 2%（Adjust）

### 3.4 区域差异（留存与付费）

| 区域 | 特征 |
|------|------|
| **北美** | D1 留存通常最高（~30%+）；CPI 高但 LTV 也高 |
| **日本** | D30 可达 ~6.4%，显著高于美国 ~3.7%（Game Growth Advisor） |
| **东南亚 / 拉美** | 流量成本低、量大；留存与 ARPU 通常低于北美 |
| **中东 / 土耳其** | TikTok Mini Games 已布局；年轻人口红利 |

## 4. 粘性：指标框架

### 4.1 核心指标定义

```
热度（Reach）          粘性（Engagement / Retention）
─────────────────      ─────────────────────────────
MAU / 月访问            DAU / MAU（Stickiness）
Install / Play 转化率   D1 / D7 / D14 / D30 留存
Gameplay 总次数         会话时长、Sessions/User/Day
分享 / 邀请系数         LTV、ARPDAU
SEO / 自然流量占比      7 日 / 30 日回流率
```

**DAU/MAU（粘性比）** = 日均活跃用户 ÷ 月活跃用户，表示「月玩家里有多少比例每天回来」。

### 4.2 留存基准（按品类）

> 来源综合：GameAnalytics 2026、Appalize、Adjust 2024、Game Growth Advisor 2026。不同数据源口径有差异，取 **区间** 用于对标。

#### 超休闲 / Instant 向（与本项目最相关）

| 指标 | 行业中位数 | Top 10% | 说明 |
|------|------------|---------|------|
| **D1** | 25%–28% | 35%–40% | 首局体验决定一切；5–15 分钟内必须感受到乐趣 |
| **D7** | 5%–8% | 12%–20% | D1→D7 是最大流失段 |
| **D30** | **1%–2%** | 4%–10% | **D30 低不代表失败**，超休闲靠量 + 广告 |
| **D90** | <1% | — | 长尾极短 |

#### 休闲 / Hybrid Casual（聚合平台可升级方向）

| 指标 | 典型区间 |
|------|----------|
| D1 | 32%–40% |
| D7 | 14%–22% |
| D30 | 5%–12% |
| DAU/MAU | 18%–25% |

#### 全游戏行业中位（GameAnalytics 2025）

| D1 | D7 | D30 |
|----|----|-----|
| ~22% | ~4% | ~0.7% |

经典 **40/20/10**（D1/D7/D30）规则已过时；2026 更现实的整体基准约 **35/15/5**，但 **超休闲仍显著低于此**。

### 4.3 粘性比 DAU/MAU 基准

| 品类 | DAU/MAU | 解读 |
|------|---------|------|
| 超休闲 | 10%–15% | 安装后短期 spike，快速衰减 |
| 休闲 / 益智 | 20%–25% | Candy Crush 级约 25%–30% |
| 社交 / Casino | 25%–35% | 社交绑定最强 |
| 游戏行业中位 | ~11.8% | 低于社交、生产力类 App |
| **警戒线** | <7% | 存在严重 engagement 问题 |
| **优秀** | ≥20% | |
| **世界级** | ≥30% | |

**注意**：游戏 **会话时长可以很长，但 DAU/MAU 仍偏低**——玩家「玩得很投入但不每天来」，这是 session-based 产品的常态。

### 4.4 Web / Instant 特有指标

| 指标 | 建议目标 | 来源/依据 |
|------|----------|-----------|
| **首屏可玩时间** | <8s | Facebook Instant Games 实践 |
| **帧率** | 60fps（中低端机） | 同上 |
| **包体** | 尽量 <25MB 级 Web 资源 | 移动 Web 弱网 |
| **PWA 安装转化** | 相对 Play 商店 **+15%–20% CVR** | ROiBest 2026 行业文章 |
| **会话时长** | Browser 平台常见 **15–30 min**（平台级，非单游戏） | 第三方分析 |

### 4.5 会话行为（Adjust 2023）

- 安装后 **D1 平均 1.93 次/session**，**D2 降至 0.63**  
- 超休闲 D2 跌幅最大；Simulation 类留存最好  
→ **次日回访机制**（Push、邮件、社交提醒）对 Web 端尤为关键

## 5. 平台对比：热度 vs 粘性潜力

| 平台 | 热度 | 粘性潜力 | 变现 | 适合游戏类型 |
|------|------|----------|------|--------------|
| **Poki / CrazyGames** | ★★★★★ SEO + 品牌 | ★★★ 单游戏留存有限，平台靠 **多游戏切换** 拉长总时长 | 广告为主 | 超休闲、益智、.io、双人 |
| **Facebook Instant** | ★★★★ 社交图谱 | ★★★★ 好友排行榜、分享 | 广告 + IAP | 休闲、社交竞技 |
| **TikTok Mini Games** | ★★★★★ 流量红利 | ★★★ 待成熟 | IAA 为主 | 超休闲、短视频可展示玩法 |
| **Discord Activities** | ★★★ 垂直但高质 | ★★★★★ **同玩 ×6–8 时长** | IAP + 内购探索 | 多人、派对、合作 |
| **PWA 独立站** | ★★ 依赖买量 | ★★★ Push 再触达 | 无 30% 商店抽成 | 买量驱动的 Casual |

**Poki 开发者侧数据能力**（竞品参考）：提供 plays、session length、retention、traffic source 面板——聚合平台若要做开发者生态，**数据透明**是留存开发者供给的关键。

## 6. 提升粘性的策略（可落地）

按 **投入产出比** 排序，适用于海外 Web 聚合场景。

### 6.1 首日体验（影响 D1）

- [ ] **Interactive Tutorial**：边玩边教，避免长文本  
- [ ] **首局 <60s 出正向反馈**（音效、进度条、里程碑）  
- [ ] **加载优化**：资源分包、懒加载、CDN；目标 **TTI <8s**  
- [ ] **延迟注册**：先玩后绑账号（Facebook Login / 邮箱）

### 6.2 每日回流（影响 D7 / DAU/MAU）

| 机制 | 建议 | 风险 |
|------|------|------|
| **Daily Reward** | 优先 **累计日历**（错过不清零），慎用纯 Streak | Streak 重置导致 casual 用户流失（约 2.6× 惩罚效应） |
| **Daily Challenge** | 轻量 rotating 目标 | 需控制难度曲线 |
| **Push / 再营销** | 行为触发（好友超越、活动结束）而非轰炸 | Web Push 权限率低 |
| **邮件召回** | 对绑邮用户有效 | 海外需注意 GDPR/CAN-SPAM |

### 6.3 社交层（影响 D30 / DAU/MAU，Discord 已验证）

- 好友排行榜（异步，不要求同时在线）  
- 分享成绩 / Referral 奖励（Discord SDK 支持 `referrer_id` 深链）  
- **同玩加成**：Discord 数据显示链接账号玩家 **+25% 启动天数、+16% session**  
- 避免 **强制多人** 才能推进进度——社交应是增益项

### 6.4 Meta 层与 LiveOps（Hybrid 化，拉高 D7+）

- 收集 / 皮肤 / 关卡地图（Roguelite Meta）  
- **限时活动** + 赛季重置 → FOMO  
- Battle Pass（免费轨 + 付费轨，免费轨作付费锚点）  
- 内容更新节奏：D3–D10 是 Hybrid Casual **最大流失窗口**，Meta 层应在此之前解锁

### 6.5 聚合平台层（本项目差异化）

```
单游戏粘性有限  →  平台通过「发现 + 账号 + 跨游戏进度」拉高总粘性
```

| 能力 | 作用 |
|------|------|
| **统一账号 & 云存档** | 降低换游戏 / 换设备流失 |
| **平台级 Daily Quest** | 「今天玩 3 款不同游戏领奖」→ 提升 cross-game DAU |
| **Continue Playing / 历史** | 一键回到上次进度 |
| **策展 + 个性化推荐** | 提升首次匹配成功率 → 间接提升 D1 |
| **Creator Analytics** | 吸引供给端 → 内容 freshness → 平台 MAU |

## 7. 对 microGameRepository 的指标建议

### 7.1 平台级 KPI（海外首发）

| 阶段 | 指标 | 初期目标（参考） |
|------|------|------------------|
| 获客 | 月独立访客、Play 转化率 | Play/Visit ≥ 40%（Web 聚合优秀线） |
| 活跃 | MAU、DAU、DAU/MAU | DAU/MAU ≥ 12% 起步，≥18% 为健康 |
| 留存 | 平台 D1/D7（任意游玩） | D1 ≥ 20%；D7 ≥ 8% |
| 深度 | 人均 Sessions/日、总时长 | Sessions ≥ 1.5/DAU；时长 ≥ 12 min |
| 供给 | 活跃游戏数、1M+ plays 游戏数 | 参考 Poki：~1000 款达 1M plays/年 |
| 变现 | ARPDAU、广告 Fill Rate | 超休闲 ARPDAU $0.03–$0.08 |

### 7.2 单游戏 KPI（接入开发者）

| 类型 | D1 | D7 | D30 | DAU/MAU |
|------|----|----|-----|---------|
| 超休闲 | ≥25% | ≥5% | ≥1% | 10%–15% |
| 休闲 / 益智 | ≥32% | ≥12% | ≥5% | 18%–25% |
| 社交 / 多人 | ≥28% | ≥10% | ≥4% | 20%+ |

### 7.3 监测与实验

- 按 **国家 / 设备 / 流量来源** 分 cohort，北美与东南亚分开看  
- 建立 **D1→D2→D7 漏斗**，定位最大 drop-off 日  
- A/B：**Daily Reward 累计 vs Streak**、**推荐位算法**、**首屏游戏数**  
- 关注 **GameAnalytics / Adjust** 公开报告年度更新

## 8. 风险与局限

1. **留存天然偏低**：不要用 Native Mid-core 的 D30 标准衡量超休闲 Web 游戏  
2. **数据口径**：MAU（平台）vs MAU（单游戏）、Visit vs Unique User 不可直接对比  
3. **隐私法规**：欧盟 GDPR、美国 COPPA（儿童）、各州隐私法影响追踪与 Push  
4. **平台依赖**：Facebook/TikTok/Discord 政策变化影响分发  
5. **广告环境**：eCPM 随季节与地区波动，影响 ARPDAU 与买量 ROI
